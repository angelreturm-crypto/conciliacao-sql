# conciliacao-sql
Conciliação de Taxas MDR de cartões

O posto em que eu trabalhava utilizava maquininhas TEF como principal meio de pagamento via cartão. Por conveniência, havia recentemente começado a estudar SQL (Structured Query Language) por meio de cursos online. Em uma semana estudando, decidi tentar oferecer um serviço de conciliação de taxas MDR para o meu chefe. Sendo assim, escrevi o código, pedi para a IA gerar planilhas simulando dados do posto e fiz o código rodar. O chefe não aceitou, alegando que fazia a conciliação manualmente; mas o código funcionou perfeitamente.
